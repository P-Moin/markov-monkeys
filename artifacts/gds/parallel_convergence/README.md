# Parallel convergence GDSII layouts

These files are the published layouts for the selected 17 ns parallel
convergence candidate (Experiment 18):

| File | Source |
|---|---|
| `markov_top_converge.gds` | OpenLane final stream-out |
| `markov_top_converge.klayout.gds` | KLayout stream-out |
| `markov_top_converge.magic.gds` | Magic stream-out |

The three views are retained to make layout inspection and stream-out
cross-checking straightforward. See
[the final physical metrics](../../../docs/final_physical_metrics.md) for the
tool versions, implementation metrics, and remaining violations.
